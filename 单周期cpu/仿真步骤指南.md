## 1. 用 RARS 把 .asm 转成 .mem（机器码）

> 💡 机器码已生成在 `测试程序\机器代码\`（5 个 `.mem`），无需再转。
> 以下步骤供你自己改程序后重新转换时使用。

### 1.1 图形界面方式（推荐）

1. 打开 RARS：双击 `工具\rars1_6.jar`（RARS 为外部软件，未收录进仓库，需自备；另需安装 Java，命令行 `java -version` 可查）
2. `File → Open` 打开要转换的 `.asm`（如 `inst26_test.asm`）
3. `Run → Assemble`（快捷键 F3）。若汇编报错，按提示修改（一般是写错了指令）
4. `File → Dump Memory`：
   - 弹窗里 **Data Segment 那一栏选 `.text`，Format 选 `Hex Text`**
   - 点 `Dump To File`，保存为对应名字的 `.mem`，如 `inst26_test.mem`
5. 检查生成的 `.mem`：每一行应是一条 32 位十六进制机器码，例如 `00500093`

### 1.2 命令行方式（备选）

```bash
java -jar 工具\rars1_6.jar a dump .text hex inst26_test.mem inst26_test.asm
```

> 说明：我们的 CPU 的 imem 从地址 0 起按顺序加载（`rom[addr[31:2]]`，`$readmemh` 从 0 填入），而 RARS 默认把代码链接到 0x00400000 —— **这不影响结果**，因为程序内部全部使用 PC 相对分支/跳转、无绝对地址引用，机器码行的顺序就是执行顺序。所以默认配置直接 Dump 即可，不用改内存布局设置。

### 1.3 每个测试程序对应一个 .mem

| .asm | 生成的 .mem | 用途 |
|---|---|---|
| `inst26_test.asm` | `inst26_test.mem` | 26 条指令逐条验证 |
| `raw_test.asm` | `raw_test.mem` | 数据相关（转发）验证 + 计周期 |
| `loaduse_test.asm` | `loaduse_test.mem` | load-use 停顿验证 + 计周期 |
| `branch_test.asm` | `branch_test.mem` | 分支/跳转验证 + 分支代价统计 |
| `sort16.asm` | `sort16.mem` | 16 元素排序，性能基准（两代 CPU 对比） |

### 2.4 性能测试：周期计数（报告必需）

给 testbench 加一个周期计数器（在测试程序跑到 `pass` 死循环处读值即可）：

```verilog
reg [31:0] cyc;
always @(posedge clk) begin
    if (rst) cyc <= 0;
    else     cyc <= cyc + 1;
end
```

跑完后在 Tcl 里 `get_value /tb_cpu/cyc`，即得**总周期数**。用同一个计数方式分别跑：
- 单周期 CPU + `sort16.mem` → 周期数 C1（理论上 C1 = 执行指令数，CPI=1）
- 流水线 CPU + `sort16.mem` → 周期数 C2

计算 `CPI = C / N`（N = 执行指令数，可以从汇编静态统计 + 循环展开算，或仿真波形里数）、`MIPS = f / (CPI×10^6)`，填入报告对比表。

## 4. 常见问题排查

| 现象 | 原因与对策 |
|---|---|
| 汇编时报错 "pseudo-instruction" | 说明用到了 `li/la/bnez/j/ret` 等伪指令——本套 .asm 已避免，若自己改写了需检查 |
| 仿真时 imem 全为 x | `.mem` 没放到仿真工作目录，或文件名与 `$readmemh` 不一致；检查 xsim 目录下有无报错文件加载 |
| 数据段结果不对（排序乱序） | dmem 太小（改 512 字）或数据基址不是小地址（基址 x20 必须是 addi 出来的小值，不能指望 RARS 的 .data） |
| 仿真跑不完 | testbench 的 `#2000` 时间太短，改成 `#2000000`（当前版本已改好） |
| 新指令（and/ori/jal 等）不执行 | 若你打开的还是老工程未刷新 → 确认 `CPU.v` 是扩展版（`SingleCycleCPU\project_1\project_1.srcs\sources_1\new\CPU.v`，8 条原版是 `CPU_8ins_backup.v`） |
